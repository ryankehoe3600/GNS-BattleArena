# GNS Battle Arena 

**A 3D single-player and online multiplayer arena shooter developed using Unity, C# and Photon PUN.**

Developed as part of my Games Networking and Security module at the University of Westminster.

## Game Features

### Online Multiplayer
- Two-player online combat using Photon PUN.
- Weapon shooting and player health systems.
- Kill tracking and a three-minute match timer.
- First player to achieve three kills wins.
- If time runs out, the player with the most kills wins.
- Win/loss screen displaying match results.

### Single-Player
- Fight against five AI-controlled enemies.
- Enemies shoot back at the player.
- Enemy counter updates as bots are defeated.
- Shooting and combat mechanics.
